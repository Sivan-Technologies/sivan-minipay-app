# Sivan Ai MiniPay Mini App

Sivan Ai MiniPay is an autonomous service agreement and multi-token payment mini app designed for Opera MiniPay and modern Web3 mobile wallets on Celo Mainnet. It enables contractors, freelancers, and businesses to lock milestone-based service agreements in stablecoins (USDT, USDC, cUSD, cNGN) or native CELO, with direct NIBSS bank settlement across Nigeria.

## Executive Overview

Sivan Ai transforms gig work and contractor agreements across emerging markets by removing counterparty risk without complex intermediaries. Built natively for the Opera MiniPay ecosystem and Celo Mainnet, Sivan allows parties to establish legally clear, autonomous service agreements where funds are programmatically locked until deliverables are verified.

All on-chain transactions generated by Sivan MiniPay automatically append the ERC-8021 attribution suffix (celo_bafcc2e56bd7), ensuring full protocol transparency and verifiable track metrics for the Celo "Agents at Work" initiative.

## Key Features

1. Native MiniPay and MetaMask Integration
- Automatic injection detection for Opera MiniPay WebView (window.ethereum.isMiniPay).
- Seamless fallback and one-click connection for MetaMask on Celo Mainnet (Chain ID 42220).
- Real-time wallet event listeners for account switching and chain verification.

2. Multi-Token Stablecoin Portfolio
- Direct live on-chain balance fetching via Viem RPC for all premier Celo assets:
  - CELO (Native gas and utility asset)
  - USDT (Tether USD ERC-20)
  - USDC (Circle Native ERC-20)
  - cUSD (Celo Dollar Mento stablecoin)
  - cNGN (Compliant Nigerian Naira stablecoin)
- Live CELO valuation derived in real time to match exact wallet portfolio totals.
- Zero mock data: all balances, quotes, and calculations represent live on-chain balances.

3. Milestone-Based Service Agreements
- Milestone fund locking with defined deliverable scopes and deadlines.
- Real on-chain transfer execution with ERC-8021 attribution tags appended to transaction calldata.
- Deliverable proof verification linking directly to verified assets and pull requests.
- Instant milestone release upon client satisfaction, recording authentic Celoscan transaction hashes.

4. Nigerian Bank Cash Out (NIBSS / NIP Rail)
- Direct fiat off-ramping from Celo stablecoins to 9 major Nigerian commercial and digital banks:
  - Access Bank, GTBank, Zenith Bank, UBA, First Bank, OPay, PalmPay, Kuda Bank, Wema / ALAT.
- 10-digit NUBAN account structure validation.
- Real-world settlement speed: internal ledger and smart account settlement in 0.15s; direct credit to recipient bank account typically under 1 to 2 minutes via NIBSS/NIP rails.

## Architecture & Technology Stack

- Runtime: Modern Vanilla TypeScript and Vite
- Blockchain Interface: Viem v2 (Celo Mainnet profile, Chain ID: 42220)
- Mobile Interface: Responsive mobile-first layout optimized for Opera MiniPay mobile viewport (360px - 480px) and desktop browsers
- Attributed Calldata: ERC-8021 attribution suffix encoder appending celo_bafcc2e56bd7 to all on-chain transactions
- State Management: Reactive event-driven services with zero heavy external dependencies

## Getting Started

### Prerequisites
- Node.js version 18 or higher
- npm or pnpm
- A Web3 wallet (MetaMask configured for Celo Mainnet, or Opera MiniPay mobile browser)

### Installation

```bash
git clone https://github.com/Samswitchy/sivan-minipay-app.git
cd sivan-minipay-app
npm install
```

### Local Development

Start the development server:

```bash
npm run dev
```

Open your browser and navigate to the local server URL (typically http://localhost:5173).

### Production Build & Preview

Verify strict TypeScript compilation and bundle production assets:

```bash
npx tsc --noEmit
npm run build
npm run preview -- --port 4173
```
